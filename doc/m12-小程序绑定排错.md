# 小程序「扫码绑定」失败排错清单

面向本地联调。M12-A（账号）、M12-B（微信绑定）、成员 3（小程序公共层）交界处的问题都记在这里。

## 1. 现状：为什么扫码后点「确认绑定本人账号」只提示「服务暂时不可用」

现象：小程序扫到编号（如 `0001`）、填写口令、确认，页面只显示

> 服务暂时不可用，请稍后重试

根因不在小程序：**后端没有配置微信小程序凭证**，`/api/mobile/account/bind` 与
`/api/mobile/auth/login` 一律以业务码 `5001` 失败。

可直接复现（后端已启动时）：

~~~powershell
curl.exe -s -o - -w "`nHTTP:%{http_code}`n" -X POST http://localhost:8081/api/mobile/account/bind `
  -H "Content-Type: application/json" -d '{\"code\":\"test-code\",\"userNo\":\"0001\",\"password\":\"x\"}'
~~~

返回：

~~~
{"code":"SERVER_NOT_CONFIGURED","msg":"微信小程序凭证未配置，请联系管理员设置 wx.miniapp.app-id 与 app-secret"}
HTTP:500
~~~

链路：`ArchiveBindingServiceImpl#bind` → `WxMiniappClient#exchange` 发现
`wx.miniapp.app-id/app-secret` 为空 → 抛 5001 → `MobileApiSupport.httpStatusOf` 把
5001 归到 HTTP 500 → 小程序 `utils/request.js` 旧版只按状态码取文案 →
显示「服务暂时不可用」。**口令填对填错都是这个结果**，因为微信 code 换 OpenID
发生在口令校验之前。

## 2. 配置（必须做）

`application.yml` 已加好 `wx.miniapp` 节点（占位为空）。三选一填真实值：

1. 环境变量（推荐，不进仓库）：
   ~~~powershell
   $env:WX_MINIAPP_APP_ID = "wx6fdadca816f0a4bf"   # 与 mini-program/project.config.json 的 appid 一致
   $env:WX_MINIAPP_APP_SECRET = "填微信公众平台 › 开发管理 › 开发设置 里的 AppSecret"
   ~~~
2. 直接改 `application.yml` 里的占位符（本地可用，注意别提交 Secret）。
3. 新建 `config/application-local.yml`，启动参数加 `--spring.profiles.active=druid,local`。

改完**重启后端**，`wx.miniapp` 生效前一直是 5001。

验证：

~~~powershell
curl.exe -s -X POST http://localhost:8081/api/mobile/account/bind -H "Content-Type: application/json" `
  -d '{\"code\":\"bad\",\"userNo\":\"0001\",\"password\":\"x\"}'
~~~

应变成 `WX_CODE_INVALID`（4002，HTTP 400）——说明凭证已生效，`code` 只是假的。

## 3. 绑定成功需要的三个条件

| 条件 | 说明 | 不满足时的现象 |
| --- | --- | --- |
| 后端配好微信凭证 | 见第 2 节 | `服务端未配置小程序凭证（wx.miniapp）` |
| 小程序能连到后端 | 开发者工具用 `http://localhost:8081` 可以；真机要换电脑局域网 IP（如 `http://192.168.1.20:8081`）并保持 `urlCheck:false`；发布必须是 HTTPS 合法域名 | `网络连接失败` / `请求超时` |
| 输入的是该账号的**后台登录密码** | 见第 4 节 | `平台账号口令不正确，请重新输入` |

## 4. 账号与口令口径：编号 ≠ 登录账号

- `sys_user.user_no`（如 `0001`）是**对外业务编号**，也是二维码里唯一的内容；
- `sys_user.login_name`（如 `admin`）才是**登录账号**；
- 小程序绑定时校验的口令 = 该账号的**若依后台登录密码**，算法与 PC 登录完全一致
  （`MD5(login_name + 口令 + salt)`，见 `ArchiveBindingServiceImpl#matchesPassword`），
  **不是编号，也不是手机号**；
- 管理员在「档案账号管理 › 新增账号」里建的账号，**初始口令 = 登录账号**
  （`ArchiveAccountServiceImpl#saveAccount`，页面保存成功时也会提示）。

口令在库里只有摘要 + 盐，任何页面都查不到明文。忘记/需要统一时：

- 系统管理 › 用户管理 › 重置密码，或
- 该账号本人登录后台后：个人中心 › 修改密码。

## 5. 「档案账号管理」和若依「用户管理」是同一批账号

两张页面操作的是**同一张表 `sys_user`**（`ArchiveAccountServiceImpl` 用的是
`SysUserMapper`），不存在第二套账号体系。区别只在页面与字段：

| | 系统管理 › 用户管理（若依原生） | 档案账号管理（M12-A） |
| --- | --- | --- |
| 数据来源 | `sys_user` | `sys_user`（同一张表） |
| 额外字段 | 无 | 用户编号、是否档案员、密级上限 |
| 「删除」语义 | 逻辑删除 `del_flag='2'` | 只提供停用（`status='1'`），记录保留可恢复 |
| 特色操作 | 重置密码、分配角色 | 生成绑定二维码、解除微信绑定、Excel 导入/导出、统计 |
| 权限点 | `system:user:*` | `arc:account:view` / `arc:account:manage` |

所以「0001」在账号管理里看起来像个新东西，其实就是 `admin` 的编号；
在账号管理里新增的账号，也会立刻出现在用户管理里，并且可以登录后台。

## 6. 错误码对照（小程序端已按此映射中文）

| 字符串码 | HTTP | 触发场景 | 提示 |
| --- | --- | --- | --- |
| `TOKEN_INVALID` | 401 | 令牌过期/撤销/绑定版本变化 | 登录已失效，请重新登录 |
| `ACCOUNT_UNBOUND` | 401 | 微信未绑定 | 请先扫码绑定 |
| `ACCOUNT_DISABLED` | 403 | 账号停用 | 账号已停用，请联系管理员 |
| `PASSWORD_MISMATCH` | 403 | 口令错误 | 平台账号口令不正确，请重新输入 |
| `USER_NO_NOT_FOUND` | 404 | 编号不存在 | 请核对管理员提供的编号 |
| `ALREADY_BOUND` | 409 | 微信或账号已被绑定 | 需管理员解除旧绑定 |
| `WX_CODE_INVALID` / `WX_CODE_USED` | 400 | code 无效/已用 | 重新进入小程序 |
| `SERVER_NOT_CONFIGURED` | 500 | 未配 AppID/AppSecret | 联系管理员 |
| `WX_SERVICE_UNAVAILABLE` | 500 | 微信服务异常 | 稍后重试 |

改动前 `utils/request.js` 只映射了 6 个字符串业务码（`ACCOUNT_*`、`ALREADY_BOUND`、`QR_*`），
`PASSWORD_MISMATCH`、`USER_NO_NOT_FOUND`、`SERVER_NOT_CONFIGURED` 等全落空，
于是口令错误被 `403` 说成「没有权限」、凭证缺失被 `500` 说成「服务暂时不可用」，
这正是本次最迷惑人的地方。

## 7. 没有真实 AppID/AppSecret 时怎么演示

`wx.miniapp.code2session-url` 支持指向本地桩服务（`doc/m12-binding-integration.md` §2.2）。
起一个只回 openid 的桩，把该配置指过去，即可在无外网、无 AppSecret 的情况下跑通
「扫码 → 校验口令 → 写入 wx_binding → 签发令牌 → 自动登录」整条链路（仅用于本地验收，
不能用于发布）：

~~~powershell
# 保存为 wx-stub.ps1，先运行它，再把 code2session-url 指到 http://127.0.0.1:9090/sns/jscode2session
$listener = [System.Net.HttpListener]::new()
$listener.Prefixes.Add('http://127.0.0.1:9090/')
$listener.Start()
while ($true) {
  $ctx = $listener.GetContext()
  $body = '{"openid":"dev-openid-0001","session_key":"stub"}'
  $bytes = [System.Text.Encoding]::UTF8.GetBytes($body)
  $ctx.Response.ContentType = 'application/json; charset=utf-8'
  $ctx.Response.OutputStream.Write($bytes, 0, $bytes.Length)
  $ctx.Response.Close()
}
~~~

注意：一个 OpenID 只能绑一个账号（`wx_binding.uk_wx_binding_open_id`），
桩服务固定同一个 openid 时，换账号测试前要先在「档案账号管理 › 详情 › 解除微信绑定」。

## 8. 绑定后仍然不对，按这个顺序查

1. 账号管理清单「微信绑定」列是否变「已绑定」——变了说明后端已成功；
2. `select * from wx_binding where status = 1;` 是否有记录、`bind_version` 是否为 1；
3. `select * from wx_token where revoked_at is null;` 是否有未撤销令牌；
4. 小程序个人中心是否显示姓名/角色；权限为空说明该账号没有任何角色菜单权限
   （`ISysMenuService#selectPermsByUserId`），业务页会按无权限隐藏；
5. 退出小程序后重新进入，会用 `wx.login` 新 code 自动恢复登录态；
   若要换绑，先「解除微信绑定」再重新扫码。
