# M03 档案分类管理首批交付

## 本地运行

1. 在已初始化若依的 MySQL 8 开发库执行 `sql/ams_member2_catalog.sql`，再执行 `sql/ams_member2_catalog_menu.sql`。重复执行会保留目录数据与已有菜单。已有若依库无需重跑会清表的初始化脚本。
2. 按仓库本地配置示例使用自己的数据库连接，使用 JDK 17 和 Maven 启动 `ruoyi-admin`。首次测试可以用本地的若依管理员。不要提交本地配置、口令或构建产物。
3. 登录后打开左侧「档案分类管理」，也可访问 `/archive/catalog`。`archive:catalog:view` 允许打开页面、查看详情、查询与导出。`archive:catalog:manage` 与查看权限配合，允许新增、编辑、停用、下载模板和导入。请在角色管理按需要授予。

## 页面和设计

- 可以新增全宗、多级分类、档案集和逻辑文件夹，编辑名称、编码、上级和顺序，查看详情和完整路径。全宗是根节点，分类只挂在全宗或其他分类下。
- 目录树和列表共用名称或编码、类型、状态的组合查询及独立排序。页首计数针对整个查询结果。打印和 Excel 导出覆盖全部匹配记录。
- 删除类验收使用停用。目录的主键 ID 保留，便于历史档案引用。启用节点需要各级上级均启用。有启用子节点时不能停用父节点。后端使用事务锁防止同时移动造成循环，用版本号拒绝覆盖别人已经保存的修改。
- Excel 导入使用页面下载的 `.xlsx` 模板，按上级编码建立层级。同批新建时，把上级行放在下级行之前。每批最多 1000 条，出现无效记录时整批回滚，提示出错行。导入为新增模式，更新已有记录请使用编辑功能。

## 建档模块接入

成员 1 在建档服务中注入 `ArchiveCatalogService`。调用 `registrationChoices(keyword, allowed)` 获取允许建档的启用末级分类，返回稳定的 `id`、分类编码、名称和完整路径。将所选 `id` 作为档案的 `categoryId`。保存档案时在业务事务中调用 `requireRegistrationCategory(categoryId, allowed)` 复核权限和状态。调用方根据当前账号计算 `allowed`，授权结果不从客户端取值。

首批交付包括目录定义和维护。档案集与真实档案的关联、跨部门可见范围的端到端联调和小程序查档在对应模块接入后验收。页面统计的单位是目录节点。

## 首批自测

在独立 MySQL 开发库执行两个增量脚本各两次，核对目录表正常、菜单及维护权限各只有一条。Maven `verify` 通过。使用本地若依管理员和普通只读角色分别检查访问权限。

| 验收操作 | 本次结果 |
|---|---|
| 页面新增全宗及两级分类，重新查询并打开详情 | 可从 MySQL 读取，显示完整目录路径 |
| 组合筛选并切换列表，打印筛选结果 | 列表、节点计数及打印内容对应本次查询 |
| 新增重复编码、将父级移到子级下、将分类挂在逻辑文件夹下 | 后端拒绝并说明原因 |
| 停用有启用子项的节点，或用旧版本再次编辑 | 后端拒绝；合法停用保留目录记录 |
| 下载 Excel 模板，先导入含重复项的文件，再导入有效层级并按条件导出 | 错误提示含行号且整批回滚，修正后导入成功，导出保留上级编码 |
| 普通只读账号查看，再尝试直接调用写入接口 | 可读但拒绝写入，数据库未新增记录 |
